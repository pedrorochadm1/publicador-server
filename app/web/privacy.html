Política de Privacidade

Última atualização: junho de 2026.

Esta ferramenta (“Publicador”) é um sistema interno de Dr. Pedro Rocha (@pedrorochadm1) para publicar conteúdo do próprio criador no Instagram, YouTube e TikTok. Esta política explica como os dados são tratados.

1. Dados que tratamos

  • Autorização do TikTok: ao conectar sua conta, recebemos um token de acesso e informações básicas do perfil (apelido, opções de privacidade da conta) via a API oficial do TikTok, exclusivamente para permitir a publicação que você solicitar.
  • Conteúdo: o vídeo/imagens e a legenda que você escolhe publicar.

2. Como usamos

Os dados são usados apenas para executar a publicação que você autoriza expressamente. Não vendemos, alugamos nem compartilhamos seus dados com terceiros para publicidade.

3. Armazenamento e retenção

Os tokens de acesso ficam armazenados de forma restrita no servidor apenas pelo tempo necessário para a publicação. A mídia enviada é apagada do servidor logo após a publicação. Tokens de sessão da interface web expiram em até 24 horas.

4. Compartilhamento com o TikTok

Ao publicar, o conteúdo e as configurações escolhidas (privacidade, interações, divulgação comercial) são enviados ao TikTok pela API oficial e passam a ser regidos pelos Termos e Política de Privacidade do TikTok.

5. Seus controles

Você pode desconectar a conta a qualquer momento (botão “Sair”), o que remove o token da sessão. Você também pode revogar o acesso do app nas configurações da sua conta TikTok.
